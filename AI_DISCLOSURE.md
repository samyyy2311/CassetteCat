# AI Disclosure

CassetteCat is built and maintained by its developer.

I sometimes use Claude Code and CodeRabbit while working on the project, mainly
for bug fixes, code review, cleanup, and spotting issues.

Any suggested changes are checked and tested before they are committed.

The project’s features, design, architecture, and implementation decisions are
still made by me.

The existing [Contributing](CONTRIBUTING.md) rules still apply, including the
rule against copying code from other projects.

Licensing also stays the same:

- `app/` and `firmware/`: GPL-3.0
- `hardware/`: CERN-OHL-S-2.0

CassetteCat itself does not use AI. It does not call AI services, send listening
data for AI processing, or include an AI model.

This note is only about tools used during development.
