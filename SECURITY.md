# Security Policy

## Supported Versions

Only the latest release and the current `main` branch receive active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1.0 | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability in CassetteCat, please report it responsibly rather than opening a public issue.

### Preferred Method: GitHub Private Vulnerability Reporting
Please submit your report through GitHub's [Private Vulnerability Reporting](https://github.com/samyyy2311/CassetteCat/security/advisories/new) feature on this repository.

### What to Include
When reporting a vulnerability, please provide:
1. A clear description of the issue and its potential impact.
2. Step-by-step reproduction steps or a minimal proof of concept.
3. Affected components (for example, credential storage, network communication, or file handling).

Reports will be reviewed and addressed promptly. Please allow reasonable time for a fix before disclosing any details publicly.
